# План разработки

## 1. Принципы
Вертикальные срезы. В конце каждого спринта: сборка, тесты, миграции, документация, обновление `CLAUDE.md`, отчёт по формату §19 ТЗ (что реализовано; созданные файлы; изменённые файлы; технологии; тесты; результат сборки; оставшиеся проблемы; следующий этап). Фича не «готова» без тестов. Следующий спринт начинается только после подтверждения заказчика. Эквайринг и реальная отправка WhatsApp — в конце, по мере получения доступов; домен готовится раньше.

## 6. Вопросы и принятые решения

### 6.1. Бизнес-правила — приняты значения по умолчанию (настраиваемые, требуют подтверждения заказчика)
Заказчик поручил архитектору решить на своё усмотрение (2026-11-20). Все значения — настройки `HotelSettings`, владелец меняет их без доработки кода.

| № | Вопрос | Решение по умолчанию |
|---|---|---|
| 3 | Отмена и предоплата | Предоплата 0% (оплата при заезде), владелец может задать процент. **Штрафов по умолчанию нет (решение заказчика 2026-11-21):** поздняя отмена, No-Show и досрочный выезд — 0 ночей; отмена бесплатна в любое время. Владелец может включить штрафы (например, 1 ночь); тогда бесплатная отмена — до 24 ч до заезда. Штраф начисляется как долг по брони (без автосписания) |
| 4 | Время заезда/выезда | Заезд 14:00, выезд 12:00. Ранний заезд/поздний выезд — платные услуги из справочника, добавляет администратор |
| 5 | Веб-бронь до эквайринга | Ручное подтверждение (`AutoConfirmWebBookings=false`); `Pending` держит номер 24 ч (`PendingHoldHours`), затем `Expired`. No-Show фиксируется фоновой задачей в 12:00 дня после даты заезда (`NoShowCutoffTime`) |
| 6 | Тарифы | Цена за ночь у категории + переопределение у номера + сезонные периоды и цены выходных + скидки/промокоды. Завтрак и доп. место — услуги. Детских тарифов нет (решение заказчика 2026-11-22): дети учитываются только во вместимости |
| 7 | Дети и размещение | Дети учитываются во вместимости (взрослые + дети ≤ вместимость). Доп. место — услуга. Питомцы — текстом в правилах отеля |

### 6.1a. Правила почасовых броней — решение заказчика (2026-11-21)
Настройки владельца (`HotelSettings`). Sprint 5: удержание, бесплатная отмена, расчёт и запись штрафов, неявка (вручную; автоматически — настройкой `AutoNoShowEnabled`, с Sprint 7 по умолчанию включена для новых гостиниц, у существующей — как настроил владелец). Приём оплаты штрафов — Sprint 6, досрочный выезд — Sprint 7 (реализованы).

| Правило | Посуточно (как было) | Почасово (решение) |
|---|---|---|
| Бесплатная отмена | всегда (штрафов нет); если владелец включит штраф — до 24 ч до заезда | всегда (штрафов нет); если владелец включит штраф — до 2 ч до начала |
| Штраф за позднюю отмену | 0 (по умолчанию; можно задать, например 1 ночь) | 0 (по умолчанию; можно задать, например 1 час по цене часа брони) |
| Неявка (No-Show) | в 12:00 следующего дня | через 30 мин после начала: статус «Неявка», номер освобождается |
| Штраф за неявку | 0 (по умолчанию) | 0 (по умолчанию) |
| Неподтверждённая бронь держит номер | 24 ч, но не позже начала брони | 30 мин, но не позже начала брони |
| Досрочный выезд | оплата фактических ночей | оплата фактических часов, остаток не возвращается |
