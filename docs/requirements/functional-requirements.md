# Функциональные требования HMS

Приоритет: **P0** — MVP, **P1** — после MVP, **P2** — после получения доступов эквайринга/WhatsApp.

## Модули
| Код | Модуль |
|---|---|
| IAM | Пользователи, роли, права |
| ROOM | Номерной фонд, категории, статусы |
| RATE | Тарифы, скидки, услуги |
| BOOK | Бронирования и доступность |
| CAL | Календарь |
| GUEST | CRM гостей |
| FRONT | Check-in / Check-out |
| HK | Уборка и техобслуживание |
| FIN | Платежи, возвраты, расходы |
| PAY | Онлайн-эквайринг (адаптеры) |
| WA | WhatsApp |
| RPT | Дашборд владельца и отчёты |
| PORTAL | Публичный портал и кабинет гостя |
| SYS | Настройки, аудит, фоновые задачи |

## IAM
- IAM-1 (P0) Вход по email/телефону + пароль, refresh токена, выход.
- IAM-2 (P0) Владелец управляет администраторами и уборщиками (создание, блокировка).
- IAM-3 (P0) Права администратора настраиваются владельцем (набор Permission).
- IAM-4 (P0) Регистрация гостя; подтверждение email (подтверждение по WhatsApp OTP — P2).
- IAM-5 (P1) Сброс пароля.

## ROOM
- ROOM-1 (P0) CRUD номеров; архивирование вместо удаления, если есть история.
- ROOM-2 (P0) Категории: вместимость, кровати, удобства, фото, описание.
- ROOM-3 (P0) Статусы Available/Reserved/Occupied/Cleaning/Maintenance/OutOfService + история с автором и причиной.
- ROOM-4 (P0) Допустимые переходы статусов (state machine).

## RATE
- RATE-1 (P0) Базовая цена за ночь у категории, переопределение у номера.
- RATE-2 (P1) Сезонные периоды, цены выходных.
- RATE-3 (P1) Скидки (процент/сумма, промокод, период, мин. ночей).
- RATE-4 (P0) Справочник дополнительных услуг.

## BOOK
- BOOK-1 (P0) Создание (админ/гость), редактирование, смена дат/номера, добавление гостей, отмена.
- BOOK-2 (P0) Проверка доступности на backend, интервал [CheckIn, CheckOut).
- BOOK-3 (P0) Защита от гонок: exclusion constraint в PostgreSQL + транзакция.
- BOOK-4 (P0) Расчёт стоимости только на backend; цена фиксируется в брони (snapshot).
- BOOK-5 (P0) Статусы: Pending, AwaitingPayment, Confirmed, CheckedIn, CheckedOut, Cancelled, NoShow, Expired.
- BOOK-6 (P0) Правила отмены (владелец): окна бесплатной отмены, штраф.
- BOOK-7 (P0) История всех изменений (BookingHistory).
- BOOK-8 (P0) Предоплата: процент или сумма; частичная/полная оплата.
- BOOK-9 (P0) Фоновое истечение неоплаченных броней (Expired) и NoShow.

## CAL
- CAL-1 (P0) Сетка «номера × дни», цвета статусов, фильтр по категории.
- CAL-2 (P0) Заезды/выезды дня.
- CAL-3 (P1) Drag&drop перемещение и смена дат (тот же API с проверкой конфликтов).
- CAL-4 (P0) Быстрое создание брони выбором диапазона.

## GUEST
- GUEST-1 (P0) CRUD, поиск, фильтры, заметки, история бронирований/платежей/проживаний.
- GUEST-2 (P0) Счётчик визитов, сумма расходов (полученные платежи минус возвраты).
- GUEST-3 (P0) Документы — отдельное ограниченное право, шифрование чувствительных полей.
- GUEST-4 (P0) Согласия (обработка ПД, WhatsApp) с датой и источником.
- GUEST-5 (P1) Слияние дублей.

## FRONT
- FRONT-1 (P0) Check-in: поиск брони, проверка гостя/оплаты, назначение номера, Occupied, фиксация времени.
- FRONT-2 (P0) Check-out: задолженность, доп. услуги, окончательная оплата, номер → Cleaning, авто-задача уборки.
- FRONT-3 (P0) Всё в истории и аудите; повторный вызов безопасен (идемпотентность).

## HK
- HK-1 (P0) Авто-задача после Check-out, ручное создание, приоритет, назначение.
- HK-2 (P0) Статусы: Pending, Assigned, InProgress, Completed, Inspected, Rejected.
- HK-3 (P0) Чек-листы (шаблоны по категории).
- HK-4 (P0) Completed не освобождает номер, если не включена `AutoReleaseRoomAfterCleaning`; по умолчанию Available после Inspected.
- HK-5 (P0) Заявки о неисправностях/повреждениях; при необходимости номер → Maintenance.
- HK-6 (P1) Фотоотчёт.
- HK-7 (P0) Уборщик не видит финансы и ПД гостей.

## FIN
- FIN-1 (P0) Способы: Cash, BankTransfer, Card (POS), MBANK, Optima.
- FIN-2 (P0) Типы: проживание, предоплата, частичная, доп. услуги, возврат.
- FIN-3 (P0) Возвраты: запрос → решение уполномоченного → фиксация (онлайн-возврат через банк — P2).
- FIN-4 (P0) Расходы: категории, поставщик, вложение, автор.
- FIN-5 (P0) Платёжные записи неизменяемы; исправление — сторно/корректировка.
- FIN-6 (P0) Задолженность = начислено − оплачено + возвращено.

## PAY (P2)
- PAY-1 `IPaymentProvider`: создание платежа, статус, возврат, проверка подписи.
- PAY-2 Webhook с проверкой подлинности и идемпотентностью.
- PAY-3 Sandbox.
- PAY-4 Сверка зависших платежей фоновой задачей.

## WA
См. `integrations/whatsapp-integration.md`.

## RPT
- RPT-1 (P0) KPI: Revenue, Net Revenue, Expenses, Net Profit, Occupancy, ADR, RevPAR, Bookings, Cancelled, Avg Stay, Outstanding, Refunds.
- RPT-2 (P0) Отчёты: день/неделя/месяц/год, брони, гости, номера, сотрудники, платежи, возвраты, расходы.
- RPT-3 (P0) Фильтры: период, категория, способ оплаты, статус, сотрудник.
- RPT-4 (P1) Экспорт Excel и PDF.
- Формулы показателей: `database/database-design.md` §8.

## PORTAL
- PORTAL-1 (P0) Каталог, поиск по датам/гостям, карточка номера, цена.
- PORTAL-2 (P0) Регистрация/вход, профиль, мои брони, отмена по правилам, история платежей.
- PORTAL-3 (P2) Онлайн-оплата, онлайн-запрос возврата.
- PORTAL-4 (P0) SSR, базовое SEO, быстрый mobile.

## SYS
- SYS-1 (P0) Настройки отеля: время заезда/выезда, правила, политика отмены, флаги.
- SYS-2 (P0) Аудит значимых действий.
- SYS-3 (P0) Фоновые задачи: истечение броней, NoShow, напоминания, ретраи WhatsApp, сверка.
- SYS-4 (P0) Резервное копирование БД.

## Нефункциональные требования
- Доступность цель 99.5% (один VPS на старте).
- Проверка доступности < 300 мс; календарь 30 номеров × 60 дней < 1 с.
- Структурированные логи, correlation id, health checks.
- Все строки через i18n-ресурсы.
- Последние 2 версии Chrome/Safari/Edge/Firefox, iOS/Android.
- Базовая a11y (клавиатура, контраст).
